# Imagens oficiais (opcional)

`superbowl.html` usa ilustrações originais (capacete/escudo/troféu estilizados)
por padrão, porque os logos dos times e as fotos do Troféu Vince Lombardi são
marcas registradas / imagens protegidas da NFL — não podem ser geradas ou
copiadas aqui.

Se você tiver os direitos de uso desses arquivos, basta soltá-los nos caminhos
abaixo com esses nomes exatos. O site detecta os arquivos automaticamente: se
existirem, substituem a ilustração; se não existirem, a ilustração original
continua aparecendo (nada quebra).

## Troféu

- `assets/trophy.png` — usado no topo (hero) e na seção "Troféu".

## Escudos dos times

Caminho: `assets/shields/<sigla>.png` (todas em minúsculo):

```
kc.png    ne.png    pit.png   dal.png   sf.png    gb.png    nyg.png   den.png
lv.png    was.png   bal.png   mia.png   ind.png   lar.png   tb.png    phi.png
chi.png   nyj.png   sea.png   no.png    buf.png   atl.png   car.png   ari.png
cin.png   ten.png   jax.png   hou.png   cle.png   det.png   min.png   lac.png
```

Formato recomendado: PNG com fundo transparente, quadrado, pelo menos 200×200px
(o site redimensiona automaticamente com `object-fit: contain`).
